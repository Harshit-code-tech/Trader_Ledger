**Implementation**:

- Handles edge cases correctly

**Rules Implemented**:

- ✅ Date validation (YYYY-MM-DD format)
- ✅ From Date cannot be after To Date

### 3️⃣ Open vs Closed Positions ✅

**Requirement**: Track open positions with avg price

**Implementation**:
- Created new module `core/open_positions.py`
- `calculate_open_positions()` function
- Computed dynamically (no database storage)
- Shows: equity, status, qty, avg price, unrealized P/L

**Logic**:
```python
After FIFO matching:
  If remaining_qty > 0 → OPEN
  Else → CLOSED
```

**Test Result**: ✅ PASS
```

  TCS: OPEN, 20 qty, Avg ₹3421.00
```
